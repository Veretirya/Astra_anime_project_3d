# Kinema Lab

Локальная студия физики с интерактивным аниме-персонажем **Mika**. Работает на React, TypeScript, Three.js и Cannon-es. Веб-камера, сервер, ключи API и аккаунт не требуются.

## Самый простой запуск

В студии нажмите **«Управление» → «Офлайн-версия»**. Откройте скачанный `Kinema-Studio.html` в современном браузере с WebGL 2. Внутри уже встроены модель, текстуры, шрифты, интерфейс и физический движок. Файл работает без интернета и установки Node.js.

В архиве проекта этот же файл находится в корне, под именем `Kinema-Studio.html`.

## Запуск для разработки

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Модель встроена в приложение: отдельный запрос к `/models/mika.glb` не выполняется. Для запуска не нужно скачивать ассеты или устанавливать Python.

## Первый эксперимент

1. Потяните Мику за кисть: закреплённое тело удерживает позу, а суставы руки реагируют на захват.
2. Выключите **«Фиксация на месте»**. Все 18 физических тел станут динамическими, и персонаж начнёт падать.
3. Зажмите конечность, поднимите её и отпустите в движении для броска. Инерция сохраняется после отпускания.
4. Для переноса всей модели выберите инструмент с четырьмя стрелками и потяните персонажа по полу.
5. Отключите **«Гравитация»** для невесомости или выберите притяжение Луны, Марса, Земли либо Юпитера.
6. Нажмите **«Сбросить»**, чтобы вернуть начальную позу, камеру и параметры. Сохранённые эксперименты не удаляются.

## Управление

| Действие | Управление |
| --- | --- |
| Захват конечности | ЛКМ на модели, инструмент G |
| Обзор на 360 градусов | ПКМ или ЛКМ на свободном месте |
| Инструмент орбиты | V |
| Перенос по полу | M, при отключённой фиксации |
| Приближение | Колесо мыши или жест двумя пальцами |
| Сдвиг камеры | Shift + ЛКМ |
| Центрирование камеры | F |
| Фиксация | P |
| Скелет | B |
| Пауза и продолжение | Пробел |
| Сохранение | Ctrl + S / Cmd + S |

Кнопка рядом с паузой продвигает симуляцию ровно на 1/60 секунды. Доступны масштаб времени от 0.25x до 2x, фиксированные ракурсы, полноэкранный режим и снимок сцены в JPEG.

## Персонаж и физика

- Полноценный объёмный GLB с сеткой, весами вершин, скелетом, встроенными текстурами и мимикой. Это стилизация по рисункам, не точная реконструкция невидимых ракурсов.
- Основа: CC0-модель VRoid Project. Причёска, открытый жилет, юбка со складками, пояс, гетры и цвета проработаны под референсы. Источник и условия использования: `public/models/LICENSE.txt`.
- Для симуляции используются 18 составных твёрдых тел и 17 физических суставов. У коленей и локтей шарниры с угловыми ограничителями. Остальные сочленения ограничивают наклон и скручивание.
- Шаг физики 1/120 секунды, контакт с полом и столкновения несмежных частей тела. Захват использует подвижную точечную связь, а не подмену анимации.
- Юбка деформируется костями бёдер. Полноценная симуляция ткани, обучение равновесию, нейросетевое управление и трекинг рук пока не реализованы.
- Отдельный GLB можно скачать, открыв **Mika** в инспекторе. В GLB содержится базовый скелет; физические ограничения и стартовая поза задаются кодом студии.

## Сохранение

«Сохранить сцену» сохраняет координаты и ориентации тел, линейные и угловые скорости, параметры симуляции, камеру и таймер. До 12 именованных сцен хранятся в `localStorage` текущего браузера. Данные не отправляются в облако. Доступность хранилища для локального HTML зависит от настроек браузера.

## Структура

| Файл | Содержимое |
| --- | --- |
| `src/App.tsx` | Студия, инспектор, управление, библиотека сцен |
| `src/studio/engine.ts` | Сцена Three.js, освещение, камера, выбор тела и перетаскивание |
| `src/studio/character.ts` | Поза, суставы, физические тела, контакты и синхронизация скелета |
| `src/studio/types.ts` | Настройки, типы и формат снимка состояния |
| `public/models/mika.glb` | Готовый персонаж с текстурами |
| `src/assets/mika-model.json` | Точная сжатая копия GLB для однофайловой сборки |
| `src/studio/modelAsset.ts` | Распаковка одной копии данных для сцены и скачивания модели |
| `scripts/build_character.py` | Воспроизводимый генератор адаптированной модели |
| `scripts/verify.mjs` | Автоматические проверки 13 рабочих сценариев в Chromium |
| `scripts/package_release.py` | Автономный HTML и архив исходников |

Для будущего обучения можно использовать наблюдения из `CharacterRig.save()`, сброс эпизода через `reset()` и фиксированный шаг `step(dt, time)`. Следующий отдельный этап: определить действия суставных приводов, функцию награды и цикл обучения. Сейчас скрытого контроллера ходьбы нет.

## Сборка и проверки

```sh
npx tsc --noEmit
npm run build
npm run preview
```

Для размещения студии достаточно `dist/index.html`, даже если хостинг не публикует папку `models`. Встроенный персонаж не зависит от имени домена и пути страницы. При замене исходного GLB запустите `python3 scripts/embed_model.py`, затем повторите сборку. `build_character.py` обновляет встроенную копию автоматически.

Для формирования файлов скачивания после сборки:

```sh
python3 scripts/package_release.py
```

Для браузерных проверок запустите `npm run dev`, затем в другом терминале:

```sh
npx playwright install chromium
node scripts/verify.mjs
```

Результаты проверки записываются в `artifacts/verification.json`. На Linux Playwright может потребовать системные библиотеки: `npx playwright install-deps chromium`.

Повторно генерировать модель необязательно. При необходимости `python3 -m pip install numpy pillow`, затем `python3 scripts/build_character.py`. Без аргумента генератор получает исходный CC0-архив, с аргументом использует путь к локальному `HairSample_Female.vrm`.

Шрифты Manrope и IBM Plex Mono поставляются локально, лицензии находятся в `public/licenses/`.
